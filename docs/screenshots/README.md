Add three PNG images to this folder, using these exact file names so they appear in the main README:

| File name | What to capture |
| --- | --- |
| `report-studio.png` | The Report Studio page (`/reports`) — the source library, the generate panel, and the AI provider status strip at the top. |

Tips: use your browser's full-page or window screenshot at a normal zoom, in light mode, with a real report on screen. Keep each image under ~1 MB if you can. Once the three files are here, commit and push and they will render in the README on GitHub.
